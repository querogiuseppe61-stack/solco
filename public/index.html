    Aggiungi musica alla biblioteca

    I file audio e le copertine vengono letti direttamente dalla posizione attuale: non viene creata alcuna copia. Il drive dovrà essere collegato per riprodurre gli album.

    Trascina qui cartelle o file audio
    formati: mp3, flac, m4a, ogg, wav, aac, opus

    Questa modalità copia i file nella cartella locale music/. Per lasciare l’archivio sul drive usa la scheda “Indicizza cartella o drive”.

    Rimuovi toglie la cartella dall’elenco ma tiene da parte i metadati già letti: se la reinserisci, gli album ricompaiono subito. Dimentica butta via anche quelli, l’analisi audio dei suoi brani e le copertine che restano senza album, utile per una cartella che non tornerà (per esempio un percorso di un altro sistema). Nessuna delle due tocca i file musicali.
